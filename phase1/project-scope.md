# Project Scope & Objectives

## Project Scope

The project will build a customer support ticket management system using Salesforce and Agentforce.

The system will:

- Automate ticket priority classification as High, Medium, or Low.
- Use Agentforce to analyze customer support ticket descriptions.
- Enable automatic assignment of tickets to appropriate support agents.
- Create urgent handling tasks for High-priority tickets.
- Provide visibility of ticket information for support agents and managers.

## Objectives

The project aims to:

- Reduce response time for customer issues.
- Improve customer satisfaction.
- Minimize manual effort in ticket handling.
- Ensure critical issues are handled first.
- Improve support-team productivity and efficiency.

## Expected Outcome

The proposed solution will reduce manual ticket prioritization and assignment effort, help identify critical tickets faster, and support more efficient handling of customer issues.
